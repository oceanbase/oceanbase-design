## API

| Property | Description | Type | Default | Version |
| :-- | :-- | :-- | :-- | :-- |
| width | Chart width | number | container width | - |
| height | Chart height | number | 400 | - |
| padding | Chart padding | number | 8 | - |
| title | Title | string | - | - |
| value | Value | number | - | - |
| prefix | Value prefix | string | - | - |
| suffix | Value suffix | string | - | - |
| layout | Layout | vertical \| horizontal | vertical | - |
| theme | Theme | light \| dark | light | - |
| colorMode | Color mode | none \| value \| background | background | - |
| chartMode | Chart mode | none \| line \| area | none | - |
| chartData | Chart data | number[] | [] | - |
| chartConfig | Chart config | [TinyAreaConfig](/charts/tiny#tinyarea) | - | - |
| textAlign | Content alignment | auto \| center | - | - |
| thresholds | Threshold and color mapping | object | - | - |
| className | Class name | string | - | - |
| style | Style | CSSProperties | - | - |
