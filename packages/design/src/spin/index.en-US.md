## API

| Parameter | Description | Type | Default | Version |
| :-- | :-- | :-- | :-- | :-- |
| gray | Whether to use gray indicator; only for default indicator; when false uses colored indicator | boolean | true | - |

- More API see antd Spin docs: https://ant.design/components/spin-cn
