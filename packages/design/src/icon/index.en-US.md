- 🔥 Fully inherits antd [Icon](https://ant.design/components/button-cn) capabilities and API, seamless migration.
- 🆕 Adds hundreds of general icons and OceanBase business icons on top of antd icons.

## Usage

Install `@oceanbase/icons` to use icons:

```bash
npm install --save @oceanbase/icons
```
