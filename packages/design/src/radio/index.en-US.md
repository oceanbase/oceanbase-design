## API

### Radio.Button

| Property | Description | Type        | Default |
| -------- | ----------- | ----------- | ------- |
| icon     | Icon        | `ReactNode` | -       |

Besides the above, `Radio.Button` fully inherits all props from antd [Radio.Button](https://ant.design/components/radio-cn#radioradiobutton).

- More props see antd Radio docs: https://ant.design/components/radio-cn
