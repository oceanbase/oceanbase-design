## API

### Radio.Button

| 属性 | 说明 | 类型        | 默认值 |
| ---- | ---- | ----------- | ------ |
| icon | 图标 | `ReactNode` | -      |

除了上述属性外，`Radio.Button` 完全继承 antd [Radio.Button](https://ant.design/components/radio-cn#radioradiobutton) 的所有属性。

- 更多属性详见 antd Radio 文档: https://ant.design/components/radio-cn
