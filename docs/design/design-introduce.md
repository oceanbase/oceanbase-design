OceanBase Design is a UI asset library from the OceanBase frontend and design team, aligned with the Ant Design design system. `@oceanbase/design` is the React implementation of OceanBase Design, built on [antd](https://ant.design/) with extensive style customization, capability extension, and encapsulation.

## ✨ Features

- 🌈 Born from real products, refined from the visual and interaction patterns of OceanBase products.
- 🎨 Aligned with the Ant Design design system, seamless migration from antd.
- ⚙️ Full-stack development and design tooling, seamless integration with the Umi framework.
- 📦 Out-of-the-box high-quality React components.
- 🛡 Built with TypeScript, complete type definitions provided.
- 🌍 Internationalization support.
