title: Avoid Errors
order: 3
---

When users perform operations, effectively prevent operational errors through reasonable constraints, pre-checks, and operation risk confirmation, helping users complete tasks smoothly.

## Reasonable Constraints

Apply necessary constraints to operations to reduce the possibility of errors. For example, when entering a verification code, use a 6-digit input to avoid incorrect digit count; disable or hide unavailable options to avoid no response or error messages when users click.

## Validation Check

Validate user input and provide timely error feedback and correction help. For example, when submitting a form, check whether user input meets requirements and prompt users to correct if errors exist.

## Risk Confirmation

Provide operation confirmation for risky and irreversible dangerous scenarios. Clearly explain the consequences of the operation to set user expectations, reduce error rates, and avoid unnecessary losses.
