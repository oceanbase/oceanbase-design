Product icons are highly abstract, symbolic graphic elements used to quickly convey information, indicate functions, or represent applications across digital platforms. They simplify interaction through visual language, improve user experience, and serve as part of brand identity to enhance interface aesthetics and consistency.

## Design Philosophy

Guide users with intuitive, refined graphic language while serving as visual brand markers. Integrate into a unified design aesthetic to deepen brand recognition and memory, building product interfaces that are both practical and distinctive.

### Extension Methods

To better inherit filled icon characteristics, two main extension methods are described below.

#### Direct Stroke

Convert filled icon shapes directly to inner strokes, preserving the same corner radii. **All stroke widths are 2px.**

![2344-14.jpg](https://mdn.alipayobjects.com/oceanbase_design/afts/img/9CnVQKwg2k8AAAAAAAAAAAAADv3-AQBr/original)

#### Shape Welding

For some icons, gaps between two-tone shapes can be converted to lines that connect the two shapes.

![2344-15.jpg](https://mdn.alipayobjects.com/oceanbase_design/afts/img/Shy6ToEyo7oAAAAAAAAAAAAADv3-AQBr/original)

## How to Draw

### Point

Points appear in many graphics. Discover patterns for the same element across an icon set and use them sparingly. We keep point sizes as multiples of 2.

![15.jpg](https://mdn.alipayobjects.com/oceanbase_design/afts/img/GB4OT7j2E4sAAAAAAAAAAAAADv3-AQBr/original)

### Line

Lines fall into two cases: (1) In graphic icons, all lines are 2px; (2) In letter icons, line width can be 2–5px based on visual weight depending on the number of letters.

### Corner Radius

When drawing, apply 1px corner radius only to the outer outline. **Do not round corners on internal shapes and lines.**

![圆角.jpg](https://mdn.alipayobjects.com/oceanbase_design/afts/img/Cq5wTYhxCFwAAAAAAAAAAAAADv3-AQBr/original)

### Angles

In daily design, most system icon angles can start from multiples of 5 and be applied flexibly based on context.

![17.jpg](https://mdn.alipayobjects.com/oceanbase_design/afts/img/TyRST7Zdq5sAAAAAAAAAAAAADv3-AQBr/original)
