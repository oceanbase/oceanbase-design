## Space

Use a space between text in the following scenarios:

- A space is needed between English and non-punctuation Chinese, e.g., "Create MySQL data source"
- A space is needed between numbers and non-punctuation Chinese, e.g., "Create 2 migration tasks"
- A space is needed between numbers and units, e.g., "1 GiB"

- No space between the following units and numbers:
  - Second (s)
  - Percent (%)
  - Celsius (℃)

<strong>Do not use periods in the following scenarios:</strong>

:::info

1. Component titles
2. Email addresses
3. Link text
4. Tags
5. Placeholder text
6. Form labels
7. Menu options

:::
