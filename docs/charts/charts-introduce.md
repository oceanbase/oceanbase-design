OceanBase Charts is a chart asset library from the OceanBase frontend and design team, designed to improve the development efficiency and product experience consistency of OceanBase enterprise products. It includes multiple chart types and style themes. `@oceanbase/charts` is its React implementation and OceanBase's chart best practice. In most cases, you only need to specify data-related properties without customizing chart styles and interactions to ensure the best display.

## ✨ Features

- 🌈 Born from real products, refined from visualization best practices across OceanBase products.
- 🎨 Aligned with the AntV design system, fully inherits the capabilities and API of [Ant Design Charts](https://charts.ant.design).
- ⚙️ Full-stack development and design tooling, seamless integration with the Umi framework.
- 📦 Out-of-the-box high-quality charts.
- 🛡 Built with TypeScript, complete type definitions provided.
- 🌍 Theme support.

## Supported Environments

- Modern browsers and IE11+.
- Electron
